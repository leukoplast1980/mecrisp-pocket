Phone devices and GPIO pins, plus a round of fixes and polish.

- **Phone devices:** `vibrate`, `brightness`, and tones with `tone`, `waveform`, `volume`, `silence` and `tone?`
- **16 GPIO pins:** `pin-out`, `pin-in`, `pin-high`, `pin-low`, `pin-toggle`, `pin@`, `pins@` and `pins!`
- **GPIO tab:** each pin's direction and level, a logic trace of the last 50 ms, 0.5 s or 5 s, and a tap on an input pin changes its level
- **REPL:** coloured input and output (errors in red), the input line keeps the focus, and no more empty line after every line
- **Editor:** long lines wrap, line numbers no longer overlap the text, file tabs with an unsaved-changes dot and a close button, and "Clear content" in the tab menu
- **Settings:** text size, line wrap and keep the screen on
- After an app update with a new Forth core, the app switches to it (and asks first if you have words compiled to flash)

Words compiled to flash in 0.1 were built for the old core: switching to the new one removes them, so send their source again afterwards.
