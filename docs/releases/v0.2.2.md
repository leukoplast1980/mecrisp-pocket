Comes with an example: `lightshow.fs`, a light show that uses every part of the board.

- A Knight Rider scanner on pins 0-7 and a binary counter on pins 8-11
- A "breathing" pin 12 made with software PWM: watch it in the GPIO tab at 50 ms
- A blip on every step whose pitch follows the scanner, and a breathing screen
- Pin 15 as a button: tap P15 in the GPIO tab to switch modes (it vibrates and changes the waveform and speed)

It opens in the editor on the first start; after that it is under Files ("Example: lightshow.fs"). Send it with Send > Whole file, type `lightshow`, and press Send with an empty line to stop it.

Also new: the editor scrolls with momentum. A quick swipe keeps the text gliding and slowing down, a tap stops it without moving the cursor, and the ends of the file show Android's edge effect.

Fixes:

- A program that prints without end no longer freezes the app; Stop still works
- Lines can be up to 1024 characters (was 200). A longer line is refused instead of being cut off silently
- Vibration, brightness and tones follow the latest values: a fast brightness loop ends at the value it set last
- `c!` and `h!` to a device register change only their own byte
- Negative times, frequencies and volumes count as 0 (`-1 vibrate` no longer vibrates for a minute)
- Replace all is one step for Undo, and two quick saves can no longer finish in the wrong order
- A failed flash save is tried again; lines indented with tabs get their echo coloured
- In Raw mode, ← does nothing (it used to delete a character)

The Forth core changed (bigger input buffer). If you have your own words in flash, the app offers to switch to the new core; switching clears your flash words, so send your files again afterwards.
