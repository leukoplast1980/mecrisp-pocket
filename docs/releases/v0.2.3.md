New example: `pwm-ramp.fs`. Software PWM on one pin, from 0 to 100 % in 10 s and back, in 1 % steps of a 10 ms period. Open it under Files ("Example: pwm-ramp.fs"), send it with Send > Whole file, type `0 pwm-ramp`, and watch pin 0 in the GPIO tab with the 50 ms window. Send an empty line to stop it.

Fixes from a review of 0.2.2:

- A program that prints without end no longer freezes the app; Stop still works. The console breaks output lines longer than 2000 characters
- Lines can be up to 1024 characters (was 200). A longer line is refused instead of being cut off silently
- Vibration, brightness and tones follow the latest values: a fast brightness loop ends at the value it set last
- `c!` and `h!` to a device register change only their own byte
- Negative times, frequencies and volumes count as 0 (`-1 vibrate` no longer vibrates for a minute)
- Replace all is one step for Undo, and two quick saves can no longer finish in the wrong order
- A failed flash save is tried again; lines indented with tabs get their echo coloured
- In Raw mode, ← does nothing (it used to delete a character)

The Forth core changed (bigger input buffer). If you have your own words in flash, the app offers to switch to the new core; switching clears your flash words, so send your files again afterwards.
